# Thu Chi · Email mẫu

Đây là các template email đang chạy thật, render từ `backend/src/auth/mail-templates.ts` (gửi khi gắn / đổi / gỡ số điện thoại, khi đặt lại mật khẩu và mã OTP quên mật khẩu qua email). Mở trực tiếp từng file `mail-*.html` để xem; sửa nội dung thì sửa trong backend rồi render lại, không sửa tay ở đây.
